# Task Manager Project 
## Overview
A task management and tracking tool being developed during an internship at **E-Gas (Egypt)**, requested by our cybersecurity manager to assign tasks to employees and track progress through a dashboard.

## Goals
- Assign tasks to employees
- Track task status and progress
- Provide a dashboard view summarizing team activity and task completion
- Help management follow up on work more efficiently ("accelerate" oversight of ongoing tasks)
